Tài liệu REST API Agent 3T Global (In-Browser Bridge)

Hệ thống RPC Bridge Server cho phép bạn điều khiển và khai thác toàn bộ sức mạnh tạo Video TVC, Ảnh và Chat của Agent 3T Global thông qua chuẩn REST API hiện đại. Bạn có thể gọi trực tiếp từ Google Colab, VPS từ xa, bot Telegram, kịch bản Python hoặc ứng dụng Web/Mobile mà không cần mở trình duyệt thao tác bằng tay.

✨ Tính năng & Ưu điểm vượt trội:

  • Bỏ qua độ trễ gõ phím: Tương tác trực tiếp với State Dispatcher của React composer trong trang Agent 3T Global, không phụ thuộc vào typing simulation.
  • Tự động trích xuất Video & Giải phóng Blob: Video TVC được tạo trong session gốc dạng blob:https://muse.ai/... được bridge tự động trích xuất dữ liệu nhị phân (Binary), lưu thành file MP4 hoàn chỉnh và cung cấp URL HTTP stream trực tiếp.
  • Hỗ trợ chuẩn OpenAI: Cung cấp endpoint /v1/chat/completions tương thích 100% với OpenAI SDK, LangChain, Cursor, Cline.
  • Quản lý Conversation Threads: Liệt kê, chuyển đổi và bắt đầu thread mới hoàn toàn qua API.

Gửi prompt & Sinh Video/Ảnh

Endpoint cốt lõi dùng để tương tác với Agent 3T Global. Nhận câu lệnh prompt và danh sách file ảnh/video đính kèm. Hệ thống sẽ giữ connection cho đến khi Agent 3T Global sinh hoàn tất toàn bộ nội dung văn bản và render xong Video TVC (MP4), sau đó trả về kết quả gồm nội dung và đường dẫn file video để tải/phát.

Tham số Request (JSON hoặc Multipart):

Tham số Kiểu dữ liệu Bắt buộc Mô tả
prompt string BẮT BUỘC* Câu lệnh prompt cho Agent 3T Global (có thể bỏ trống nếu đã gửi file ảnh/video).
files array | file TÙY CHỌN File ảnh / video đính kèm (multipart upload, đường dẫn cục bộ, hoặc Base64).
thread_id string | int TÙY CHỌN ID hoặc chỉ số thread muốn gửi vào (ví dụ: "thread_0", 1).
new_thread boolean TÙY CHỌN Nếu true, tự động mở một thread chat mới trước khi gửi.
timeout_ms int TÙY CHỌN Thời gian chờ tối đa (mặc định: 180000ms = 3 phút, đủ cho video render).

⚡ Chuẩn OpenAI Drop-in SDK

Cung cấp giao diện chuẩn OpenAI Chat Completions. Bạn có thể truyền Base URL này vào bất kỳ thư viện nào hỗ trợ OpenAI (openai Python, LangChain, LlamaIndex, LiteLLM, v.v.).

Python Example — Sử dụng thư viện `openai` 
from openai import OpenAI

# Kết nối trực tiếp qua Tailscale IP hoặc Localhost:
client = OpenAI(
    base_url="{BASE_URL}/v1",
    api_key="none"
)

response = client.chat.completions.create(
    model="muse-ai",
    messages=[
        {"role": "user", "content": "Tạo kịch bản TVC 15s Mỳ Quảng"}
    ]
)

print(response.choices[0].message.content)

🚀 Batch Video Song Song (Multi-Worker Concurrency)

Endpoint đột phá cho phép tạo nhiều video cùng một lúc song song bằng kiến trúc Multi-Worker Pages độc lập. Mỗi câu lệnh tạo video được phân bổ cho một luồng Worker riêng biệt với session isolation tuyệt đối, khai thác trọn vẹn băng thông backend Meta Hatch thay vì bị giới hạn tuần tự từng video một như trên giao diện web thông thường.

🌟 Hỗ Trợ Đính Kèm File / Ảnh Nhà Đất Song Song (Image-to-Video):
Hệ thống hỗ trợ truyền kèm ảnh căn nhà, thiết kế nội thất hoặc sản phẩm affiliate dưới dạng Data-URL Base64 (data:image/jpeg;base64,...), URL ảnh trực tiếp hoặc raw base64. Mỗi worker độc lập tự bóc tách ảnh, đính kèm vào composer của worker tương ứng trước khi gửi prompt. Giới hạn payload đã được mở rộng lên 100MB.

Tham số Request (JSON Body):

Tham số Kiểu dữ liệu Bắt buộc Mặc định Mô tả
items object[] KHUYÊN DÙNG - Mảng các item độc lập. Mỗi item gồm:
- prompt (string, bắt buộc): Câu lệnh sinh video.
- files (string[], tùy chọn): Mảng ảnh/file đính kèm dạng Data-URL (data:image/jpeg;base64,...) hoặc link HTTP/HTTPS.
prompts string[] TÙY CHỌN - Mảng danh sách các câu lệnh văn bản (thay thế cho items khi chỉ tạo video text-to-video thuần túy).
files string[][] TÙY CHỌN - Mảng các danh sách file tương ứng với từng prompt khi sử dụng tham số prompts.
concurrency integer TÙY CHỌN 2 Số lượng worker/trang Playwright chạy song song (hỗ trợ từ 1 đến 5 luồng).
timeout_ms integer TÙY CHỌN 180000 Thời gian chờ tối đa cho mỗi video (mặc định 180,000ms = 3 phút).

🎞️ Phát & Tải Video Trực Tiếp (HTTP Byte-Range Streaming)

Cung cấp video MP4 đã sinh với đầy đủ tính năng HTTP Range Requests (RFC 7233) qua header Accept-Ranges: bytes. Client có thể tua đến bất kỳ giây nào mà không cần tải hết toàn bộ file, nhúng trực tiếp vào thẻ <video> HTML5, phát qua Telegram Bot hoặc tải về lưu trữ.

Header Giá trị Ý nghĩa kỹ thuật
Accept-Ranges bytes Hỗ trợ tải từng đoạn byte, cho phép player HTML5 tua video mượt mà (seeking/scrubbing).
Content-Type video/mp4 Định dạng container MP4 chuẩn tương thích đa nền tảng.
Content-Length integer Kích thước file chính xác tính bằng byte.

Google Colab Integration Pipeline (Batch 3 Video Song Song)

Kịch bản Python hoàn chỉnh chạy trên Google Colab để gửi mảng prompt tới máy Mac qua Tailscale, sinh cùng lúc 3 video TVC, tải về và hiển thị phát trực tiếp trên notebook:

Python (Google Colab Notebook — Chạy 3 Video Đồng Thời) 
import requests
import json
import time
from IPython.display import Video, display

# 1. Địa chỉ Tailscale của máy Mac đang chạy Agent 3T Global
MUSE_API_URL = "http://100.95.215.84:8765"

# 2. Danh sách các câu lệnh tạo Video TVC đồng thời
prompts = [
    "Tạo video TVC 5s ly cà phê sữa đá nhỏ giọt buổi sáng",
    "Tạo video TVC 5s chiếc đồng hồ đeo tay cơ học sang trọng chuyển động",
    "Tạo video TVC 5s sóng biển vỗ vào bãi cát trắng hoàng hôn"
]

print("🚀 Đang gửi batch tạo 3 video song song tới Agent 3T Global...")
start_time = time.time()

# 3. Gửi request batch với concurrency = 3
resp = requests.post(
    f"{MUSE_API_URL}/v1/batch/chat",
    json={"prompts": prompts, "concurrency": 3, "timeout_ms": 300000},
    timeout=360
)
data = resp.json()
elapsed = time.time() - start_time
print(f"✅ Hoàn tất toàn bộ {data.get('completed')}/{data.get('total')} video chỉ sau {elapsed:.2f} giây!\n")

# 4. Tải video MP4 về Colab và phát trực tiếp trên Notebook cell:
for idx, item in enumerate(data.get("results", []), 1):
    prompt_txt = item.get("prompt")
    duration = item.get("duration_ms", 0) / 1000
    print(f"🎬 [Video #{idx}] {prompt_txt} (Render: {duration:.1f}s)")
    for media_path in item.get("media", []):
        video_url = f"{MUSE_API_URL}{media_path}"
        local_name = f"colab_video_{idx}.mp4"
        with open(local_name, "wb") as f:
            f.write(requests.get(video_url).content)
        print(f"   -> Đã tải về: {local_name}")
        display(Video(local_name, embed=True, width=360))
    print("-" * 50)
Python (Google Colab — Pipeline Video Bất Động Sản / Affiliate kèm Ảnh Base64) 
import requests
import json
import base64
import time
from IPython.display import Video, display

MUSE_API_URL = "http://100.95.215.84:8765"

def image_to_base64_data_url(file_path):
    with open(file_path, "rb") as f:
        encoded = base64.b64encode(f.read()).decode("utf-8")
        return f"data:image/jpeg;base64,{encoded}"

# Chuẩn bị danh sách các căn nhà cùng ảnh tương ứng
batch_items = [
    {
        "prompt": "Tạo video TVC 5s góc máy flycam lướt vào phòng khách căn biệt thự này, ánh sáng ấm cúng",
        "files": [image_to_base64_data_url("biet_thu_quan2.jpg")]
    },
    {
        "prompt": "Tạo video TVC 5s lia máy từ ban công nhìn ra hồ bơi căn penhouse này lúc hoàng hôn",
        "files": [image_to_base64_data_url("penhouse_thao_dien.jpg")]
    }
]

print("🚀 Đang gửi batch video Bất động sản kèm ảnh căn nhà...")
start_time = time.time()

resp = requests.post(
    f"{MUSE_API_URL}/v1/batch/chat",
    json={"items": batch_items, "concurrency": 2, "timeout_ms": 300000},
    headers={"Content-Type": "application/json"},
    timeout=360
)
data = resp.json()
print(f"✅ Hoàn tất render video bám ảnh nhà sau {time.time() - start_time:.2f}s!")

for idx, item in enumerate(data.get("results", []), 1):
    print(f"🎬 Video #{idx}: {item.get('prompt')}")
    for media_url in item.get("media", []):
        video_full_url = f"{MUSE_API_URL}{media_url}"
        print(f"   -> Link tải: {video_full_url}")
        display(Video(video_full_url, embed=True, width=360))
