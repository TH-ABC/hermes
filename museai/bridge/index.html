Agent 3T Global có thể mắc lỗi. Tất cả tính năng đều hỗ trợ qua REST API tại /v1.
Thả hình ảnh hoặc video vào đây để tải lên
Agent 3T Global — REST API Documentation
POST /v1/chat
Gửi prompt và/hoặc đính kèm file ảnh/video. Hệ thống tự động chờ Agent 3T Global sinh phản hồi và video hoàn tất, tải media về lưu cục bộ và trả về URL xem/tải trực tiếp.
cURL Command (JSON) 
curl -X POST http://localhost:8765/v1/chat \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Tạo video TVC 15s cho căn nhà này với sân thượng mát mẻ"
  }'
cURL Command (Multipart Form - Kèm Ảnh / Video) 
curl -X POST http://localhost:8765/v1/chat \
  -F "prompt=Tạo video TVC cho sản phẩm này" \
  -F "files=@/path/to/product_image.jpg"
GET /v1/threads
Lấy danh sách tất cả các cuộc trò chuyện (threads/side-chats) hiện có trên Agent 3T Global.
cURL Command 
curl http://localhost:8765/v1/threads
POST /v1/threads/switch
Chuyển sang một đoạn chat khác theo thread_id (thread_0), số index (0, 1), hoặc tiêu đề.
cURL Command 
curl -X POST http://localhost:8765/v1/threads/switch \
  -H "Content-Type: application/json" \
  -d '{"thread_id": "thread_1"}'
POST /v1/threads/new
Bắt đầu một cuộc trò chuyện mới trên Agent 3T Global.
cURL Command 
curl -X POST http://localhost:8765/v1/threads/new
GET /v1/history
Lấy toàn bộ lịch sử tin nhắn (prompt người dùng, văn bản trả lời, file video/ảnh) của cuộc trò chuyện hiện tại. Hỗ trợ query ?thread_id=thread_1.
cURL Command 
curl http://localhost:8765/v1/history
POST /v1/chat/completions
Chuẩn API tương thích 100% với OpenAI SDK, LangChain, LlamaIndex, Cursor, Cline.
Python (OpenAI SDK Drop-in) 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8765/v1",
    api_key="none"
)

response = client.chat.completions.create(
    model="muse",
    messages=[
        {"role": "user", "content": "Tạo kịch bản TVC 15s Mỳ Quảng"}
    ]
)

print(response.choices[0].message.content)
